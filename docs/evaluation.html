Policy and error analysis

Deployed threshold: 19%. Selected on validation data to minimise 1 × false alarms + 5 × missed late invoices, in illustrative cost units. This is not a euro loss estimate.

True positives 378; false positives 504; true negatives 495; false negatives 63.

Test prevalence 30.6%. PR-AUC 0.673; Brier 0.158. ROC-AUC 95% percentile bootstrap interval 0.771–0.821, using 250 resamples.

Protocol and limitations

  • 7,200 seeded synthetic observations. Chronological 60/20/20 split: 4,320 train / 1,440 validation / 1,440 test.
  • Seven issuance-time features. No payment outcome or overdue-status fields in the feature matrix.
  • Fixed forest parameters. Permutation importance is measured on validation data. The final test set is reserved for reporting.
  • Uncalibrated probability estimates. Chronological synthetic dates do not represent real concept drift or mature-label availability.
  • Historical rows are independently generated and do not model recurring customer histories. No validated fairness, causal treatment effects or financial returns.
  • Before deployment: real-world backtesting, calibration, operational capacity constraints, privacy review, authentication and outcome monitoring.
